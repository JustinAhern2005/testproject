# Clinique Médico-Esthétique Rosemère

Pre-launch website for a luxury medical aesthetics clinic opening in Rosemère, Québec in September 2028.

## Stack

Plain HTML / CSS / JS — no build tools, no dependencies.

## Structure

```
index.html        # Single-page site
css/style.css     # All styles
js/main.js        # Navbar, countdown, scroll reveal, form
```

## Sections

1. Hero — full-viewport with live countdown to opening day
2. Positionnement — brand philosophy
3. Services — 3 treatment tiers
4. Membres Fondateurs — founding member email capture form
5. À Propos — clinic vision and local SEO copy
6. Contact — address, coordinates, social links

## Development

Open `index.html` directly in a browser — no server needed.
